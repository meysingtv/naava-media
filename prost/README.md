# PROST 🍻 – das Trinkspiel (MVP)

Party-/Trinkspiel-App mit mehreren Modi, Spieler-Setup, Intensitäts-Stufen,
Strafsystem und Statistik. Neon-Design, Icons, Vibration. Expo SDK 54.

**Modi im MVP:** Wahrheit oder Pflicht (voll ausgebaut) · Ich hab noch nie ·
Most Likely To · Die Bombe.

## 🍎 Auf dem Mac im iOS-Simulator starten

```bash
cd ~/Desktop
git clone https://github.com/meysingtv/naava-media.git prost-app
cd prost-app
git checkout claude/busy-franklin-j35abf
cd prost
npm install
npx expo install expo-linear-gradient expo-haptics
npx expo start
```

Dann im Terminal die Taste **i** drücken → Simulator startet.

> Läuft schon bei dir ein Klon (z. B. `circle-app`)? Dann einfach dort
> `git pull` und in den `prost`-Ordner wechseln – der ist auf demselben Branch.
